Stack

Type and technology.

The concept is a set of self-contained static pages. This is everything they load and everything they store.

  • Typefaces

    Jost for display and Hanken Grotesk for body text, both served from Google Fonts. Free substitutes standing in for the proprietary type family used on the live site.

  • Animation

    GSAP with ScrollTrigger drives the scroll-reveal transitions. All motion is disabled automatically when the visitor prefers reduced motion.

  • Home page hero

    The animated background on the home page is rendered with the shaders package, loaded via esm.sh.

  • Cookies and storage

    No cookies are set. The only value stored is a language preference, kept in the browser's localStorage.

  • Analytics

    None. This concept runs no analytics, no tracking and no third-party beacons.
