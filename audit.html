Lot 1 · 26516L01-MO-WEB SEO · €80,000 · 24 months

We started the audit early.

On 31 July 2026 we measured the live mercator-ocean.eu homepage: one cold-cache lab pageload, instrumented through the browser performance API. Below are nine real findings, each with its evidence and its remedy. The full Lot 1 audit goes far deeper; this page shows how we work.

Findings

Nine findings from one pageload.

Severity reflects combined SEO, performance and UX impact. Every number below was measured, not estimated.

High

Homepage has no meta description

Evidence

meta[name=description] is absent from mercator-ocean.eu. Search engines improvise the snippet that represents the organisation to the world.

Remedy

Descriptions authored for every template type, generated from structured fields so editors never ship a page without one.

High

Title tag duplicates the brand

Evidence

The homepage title is "Mercator Ocean International - Mercator Ocean International": the brand twice, zero keywords about ocean forecasting, Copernicus or the Digital Twin.

Remedy

A title pattern that leads with the mission ("Ocean forecasting and digital Ocean systems") and keeps the brand once.

High

No hreflang on a bilingual site

Evidence

The site publishes English and French versions via WPML, yet zero hreflang alternates are declared. French-language search engines cannot reliably serve French users the French pages.

Remedy

Automatic hreflang pairs emitted for every translated URL, validated in Search Console. This is also foundational for Lot 3.

High

Zero next-gen images: 1,046 KB of PNG and JPEG

Evidence

14 legacy-format images and not a single WebP or AVIF. Imagery is 1,046 KB of the 1,297 KB page: 81% of everything the visitor downloads.

Remedy

Automated WebP/AVIF conversion in the media pipeline. This concept site already serves your own SST maps that way; proof below.

Medium

31 stylesheets and 25 external scripts

Evidence

The homepage requests 31 separate CSS files and 25 external JS files: classic WordPress plugin accumulation, each one a render-blocking risk and a point of failure.

Remedy

Asset audit, bundling and critical-CSS extraction; a plugin governance rule so the count cannot silently grow back.

Medium

10 of 37 images missing alt text

Evidence

27% of homepage images carry no alternative text, invisible to screen readers and to image search.

Remedy

Alt text made a required field in the CMS media workflow; a one-time editorial backfill for the existing library.

Medium

Screenshots published as content imagery

Evidence

Files named Screenshot-2026-06-29-143125.png (216 KB) serve as homepage content images: heavy, unoptimised, and unnamed for search.

Remedy

An editorial asset workflow: meaningful filenames, correct dimensions, compression on upload.

Medium

Metadata copy-paste errors on deeper pages

Evidence

The live tender page for this very consultation carries a meta description copy-pasted from a different tender (the Copernicus Ocean State Reports consultation): evidence the metadata workflow has no guardrails.

Remedy

Template-level metadata defaults plus a pre-publish checklist surfaced inside the CMS.

Medium

Interactive at 2.7 s, loaded at 4.2 s

Evidence

domInteractive 2.7 s and loadEventEnd 4.2 s in a single lab run. Lab numbers need field confirmation, but the asset weight above explains them.

Remedy

Performance budgets enforced in CI, validated against real-user CrUX field data across the full Lot 1 audit.

Method: single cold-cache pageload of mercator-ocean.eu, 31 July 2026, Chromium browser, instrumented via the Performance API (resource timing, navigation timing, DOM inspection). A production audit adds field data, crawling and log analysis; scope below.

Honesty clause

What is already right.

An audit that only criticises is a sales document. These homepage fundamentals are correctly in place today.

  • Canonical URL declared correctly
  • Viewport meta present; the site is responsive
  • Exactly one H1, and it is the right message
  • Native lazy-loading active on 32 of 37 images
  • Open Graph tags present (7) for social sharing
  • JSON-LD structured data block present

Working proof

2,071 KB → 72 KB.

This image is published on mercator-ocean.eu as a 2,071 KB PNG. The copy on this page is the same asset, resized to its display size and encoded as WebP: 72 KB. 96% lighter, visually identical at this scale.

Original PNG on your site2,071 KB
WebP on this page72 KB

Applied across the media library, this single change removes most of the 1,046 KB of homepage image weight, and it is fully automatable in the publishing pipeline.

Lot 1, delivered in full

What the complete audit covers.

This page previews the method on one URL. The contracted audit is a programme across the full estate, in both languages.

  • Full technical crawl of every indexable URL: status codes, redirects, canonical logic, index coverage, sitemap health.
  • Core Web Vitals field data from CrUX at the 75th percentile, correlated with lab traces per template.
  • Server log analysis: how search engines actually crawl the site, budget waste, orphan pages.
  • Bilingual keyword and topical mapping in English and French: ocean forecasting, Copernicus Marine, Digital Twin and the institutional vocabulary.
  • AI-search readiness: structured data depth, content extractability, and how the site surfaces in answer engines.
  • UX heuristic evaluation of the key journeys: researcher seeking data, journalist seeking a fact, institutional partner seeking governance.
  • Accessibility review against WCAG 2.1 AA with an issue register per template.
  • Competitor and SERP analysis across comparable ocean and Earth-observation institutions.
  • Prioritised roadmap: every finding scored on effort × impact, sequenced into quarters, owners proposed.
  • Re-measurement at the end of the period so the audit is accountable to its own numbers.
